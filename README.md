# Agricultural-Drought-Early-Warning-System-for-the-Maritime-Continent
This repository stores the coding notebooks utilised to download, transform and visualise the indices and indicators embedded within the drought risk status map, as well as how to develop the map at the centre of this research. Other validation strategies were used such as time series development and dataset visualisation through the MatPlotLib library, all of which is shared within this repository to improve the repeatability of this research.
